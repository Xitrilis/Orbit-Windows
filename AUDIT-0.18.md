# Orbit 0.18 — оформление по ревью Claude

Исправлены поля приглашения и адреса сервера, стили элементов Minecraft/Horizon, тема акцентов, отступы шапки Horizon, фокус в лёгком режиме, регион магазина, нижний отступ контента, поверхность диалога друзей и устаревшие уведомления при навигации. Добавлены подсказка прокрутки бокового меню, ограничение ширины контента и более крупный текст на широком экране. Декоративная рамка вращается только при наведении или фокусе; анимации приостанавливаются при уходе из окна.

Не внедрены автоматический zoom и вывод о производительности по одному замеру FPS: они требуют проверки реального WPF/CEF, DPI и влияния фоновой загрузки. Магазины не сворачиваются автоматически. Штатные select сохраняют стрелку и клавиатурное управление. Глобальный стиль не применяется к ползункам, выбору файлов и поиску внутри готовых оболочек. Иллюстративные цвета пейзажа сохранены.

Логика Steam-ссылок, загрузчика Horizon и исправления 0.17 сохранены. Автоаудит form-audit-ui.cjs включён в исходники. Windows здесь не запускалась; проверки интерфейса используют Chromium с имитацией моста. Массовое форматирование C# не проводилось.
