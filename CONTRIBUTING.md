# Участие в Orbit

Спасибо за интерес к проекту. Перед изменениями прочитайте [README.md](README.md), а для работы с ценами — [PRICE-SOURCES.md](PRICE-SOURCES.md). Orbit использует Playnite и публичные данные магазинов; новые цены должны быть привязаны к конкретному PC-изданию, стране ответа и валюте. Если подтвердить эти данные нельзя, интерфейс должен показать причину, а не предполагаемую сумму.

## Сообщить об ошибке

Откройте [issue](https://github.com/Xitrilis/Orbit-Windows/issues/new/choose) и укажите версию Orbit, Windows, последовательность действий, ожидаемый и фактический результат. Для ошибок магазина добавьте название игры, магазин, выбранную страну и время проверки. Если приложение не запускается, используйте `Orbit-Diagnostics.cmd` и приложите только проверенный вами отчёт. Не публикуйте API-ключи, пароли, cookies, файлы сессий и всю папку `engine/OrbitData`.

## Предложить изменение

Перед pull request опишите задачу и способ проверки в issue. Держите изменение по возможности в одном разделе: библиотека, магазин, интерфейс или интеграция. Обновляйте документацию, когда меняется поведение пользователя или источник данных. Существующие тесты находятся в `Source/Tests`; команды и ограничения проверок описаны в [их README](Source/Tests/README.md).

Для сборки нужны Windows, .NET 8 SDK и полный runtime Playnite 10.63. Запустите `./Source/Build.ps1`, затем `py -c "import sys; sys.path.insert(0, 'Source'); import Package; Package.verify()"`. Команды тестов интерфейса выполняются из `Source/Tests` после установки зависимостей. Полные ZIP не прикладывайте к PR без необходимости.
