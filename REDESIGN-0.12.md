# Orbit 0.12 — редизайн и исправления

В эту версию перенесён `Orbit-redesign-v2`: четыре тёмные темы, стеклянные панели, мягкое свечение, обновлённая главная, библиотека, магазин, нижняя панель загрузок и быстрый поиск. Темы **Аврора, Океан, Закат и Графит** находятся в **Настройки → Тема**; выбор хранится локально в данных встроенного браузера. Светлой темы в этом архиве ещё нет.

## Движение и доступность

Появления карточек и окон, реакции кнопок, переходы между разделами и плавное свечение используют стили редизайна. В настройках **Меньше анимаций** отключает CSS-анимации и переходы во всех разделах; системная настройка Windows «уменьшить движение» тоже учитывается. Прозрачность и размытие остаются и при отключении движения.

Если оформление работает медленно на конкретном ПК, попробуй включить **Меньше анимаций**. Встроенный браузер и плавность на конкретной Windows-системе требуют проверки; результаты Chromium на Linux не являются измерением FPS на ПК пользователя.

## Поиск и друзья

`Ctrl+F` открывает быстрый поиск по библиотеке и каталогу Steam, `Esc` закрывает. Поиск в Steam требует не менее трёх символов и настроенной страны; каталог и цены берутся из существующего механизма Orbit, с запросом к Steam. `Ctrl+K` сохраняет поиск в открытом разделе. В демонстрации внешние данные не загружаются.

Если у игры установлена другая копия, поиск выбирает установленную, не меняя сохранённый приоритет магазина. Для запущенной или устанавливаемой игры поиск предлагает открыть карточку. Результат Steam открывает сравнение цен по выбранному товару. Устаревшие ответы и ошибки не подменяют текущий запрос.

Раздел **Друзья** передаёт Steam команды открытия списка друзей, подключения по полной `steam://joinlobby/...` ссылке или по IPv4 и порту. Orbit проверяет допустимые форматы. Для действий нужен установленный Steam, вход и поддержка конкретной игры. Список друзей и онлайн-статусы показаны самим Steam, Orbit их не считывает. Передача команды не подтверждает успешное соединение.

## Что исправлено при объединении

- Уведомления об ошибках подключения больше не скрываются автоматически после первого запуска. Крестик скрывает текущие уведомления на время сессии; после перезапуска актуальные ошибки снова видны.
- Исправлен вызов Steam из раздела друзей: кнопки соединены с нативной частью. Ограничены разрешённые типы ссылок, ошибки открытия показываются пользователю.
- Быстрый поиск и подсказки используют независимые запросы. Они не отменяют основную загрузку магазина; предыдущий запрос той же подсказки отменяется.
- Результаты быстрого поиска открывают правильный товар, обработка ошибки и последующего ввода не показывает устаревшую цену/игру.
- Раньше авторедизайн пытался искать обложку по первому текстовому совпадению и ошибочно использовал общий ключ для разных игр. Вместо этого используются уже загруженные или выбранные пользователем обложки; для отсутствующей обложки показана оформленная заглушка.
- Если основной JavaScript не загрузился, заставка больше не закрывает кнопку сохранения отчёта. Когда каталог недоступен до получения библиотеки, главная перестаёт бесконечно показывать загрузочные заглушки и выводит ошибку.
- Отключены прямые запросы интерфейса к сайтам за обложками. Сетевые запросы штатных функций цен и каталога выполняет существующая нативная часть Orbit.

## Состав и установка

Исходный переданный checkpoint содержит файлы версии 0.11; его отличие от предыдущего checkpoint — дополнительное исключение `browsercache` при упаковке. Он не позволяет подтвердить, какие ещё изменения есть в актуальном репозитории GitHub. Редизайн интегрирован поверх этого checkpoint, с сохранением перечисленных в нём функций.

Полный архив включает проверенный комплект Playnite, программы Orbit и исходники. Полностью распакуй его в новую папку и запусти `Orbit.exe`. Старую папку и данные сохрани; не копируй старые файлы программы поверх новой. Для переноса настроек и аккаунтов см. `STARTUP-FIX.md`.

Пересборка из исходников: на Windows установи .NET SDK 8 и Python 3.10+, запусти `Source/Build.ps1`, затем `python Source/Package.py`. Изменение файлов UI без пересборки приводит к ошибке проверки целостности: список встроен в `Orbit.exe`.

Проверены сборка, файловая целостность, тесты нативной логики и сценарии интерфейса с имитацией моста. Реальное подключение к Steam, запуск игр/Minecraft, внешний магазин, платёж и работа CEF/WPF на Windows в этой среде не проверены. Пользовательские настройки, пароли, заметки, логи, фотографии проверок и данные аккаунтов в архив не включены.
