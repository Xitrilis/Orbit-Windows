# Minecraft: Horizon в Orbit 0.13

Horizon — экспериментальный сторонний клиент Minecraft на Rust. Он не является официальным продуктом Minecraft. Для подготовки нужны собственная лицензия Minecraft: Java Edition и поддерживаемые файлы игры. Поддержка модов, сетевой игры и отдельных команд зависит от версии Horizon.

1. Полностью распакуйте ZIP в обычную папку на Windows x64 и откройте `Orbit.exe`. Не запускайте файлы прямо из архива. Если переносите личные настройки и библиотеку со старого компьютера, сначала сделайте резервную копию папок с данными Orbit и Playnite; архив программы не содержит ваши аккаунты и миры.
2. Откройте **Minecraft → Horizon → Настроить**. Здесь можно выбрать диск и папку данных лаунчера, папку игры Horizon, папку своей Minecraft Java и папку скачанных модов/модпаков. Смена пути не переносит файлы автоматически. Данные лаунчера и игровые миры могут находиться в разных папках.
3. Нажмите **Скачать лаунчер**. Orbit пытается скачать официальный архив Horizon с GitHub и сверить опубликованную SHA-256. Если публикация не содержит сумму или загрузка недоступна, скачайте Horizon с https://playhorizon.dev/ и кнопкой **Выбрать файл** укажите распакованный `horizon-launcher.exe`. Первый вход Microsoft и возможные запросы о лицензии выполняются в Horizon. По состоянию на октябрь 2026 документация Horizon сообщает, что вход Microsoft ожидает разрешения. При этом некоторые новые выпуски требуют вход для запуска. Если выбранный выпуск требует недоступный вход, запустить игру через него пока не получится; Orbit это ограничение не обходит.
4. Нажмите **Установить** и дождитесь окончания команды; затем **Подготовить**. Можно указать папку установленной Minecraft Java или попробовать автоматический поиск. Если версия Horizon поддерживает загрузку лицензионных файлов с Mojang после входа, она доступна в настройках Orbit отдельной кнопкой. Если команда сообщает об ошибке, прочитайте ответ и проверьте сеть и настройки Horizon.
5. **Играть** передаёт запуск Horizon. Статус отправленной команды сам по себе не гарантирует, что окно игры открылось. Horizon может требовать вход в аккаунт. Windows x64 нужен Vulkan или DirectX 12; производительность заранее не гарантируется.

## Моды и сборки

Orbit предлагает поиск и проверку средствами вашей версии Horizon. Статус совместимости и подробности находятся в ответе Horizon; если формат данных версии изменился, Orbit покажет текст результата. Установка модпака: импортируйте `.mrpack` или экспорт CurseForge ZIP, изучите отчёт, введите идентификатор папки из списка и запустите перенос доступных элементов. Не все моды можно перенести. Java-код Forge/Fabric не запускается напрямую в Rust-клиенте.

Собственные `.hmod` можно добавить через кнопку или из выбранной папки скачиваний. Orbit копирует файл в `horizon-mods` выбранной папки игры, не заменяя существующий файл. После этого откройте в самой игре **Настройки → Моды**, проверьте разрешения и включите нужный мод. Модпаки и `.hmod`, появившиеся в папке скачиваний, обнаруживаются при обновлении раздела.

## Вместе и с помощником

В Orbit откройте «Друзья → Подключить сеть» или такую же кнопку в Minecraft и введите одинаковые название и пароль сети. Один участник сначала создаёт сеть в Radmin. При успешном обнаружении сети Orbit убирает окно Radmin в фон; соединение и версии на обоих ПК нужно проверить отдельно. Доступность подключения по коду или адресу зависит от версии Horizon и выбранного способа игры; Orbit не проверяет соединение Radmin. Не публикуйте коды приглашений.

Для кадра откройте Horizon в оконном или безрамочном режиме и нажмите **Ctrl + Shift + Space**. Снимок можно посмотреть и отметить для отправки с вопросом в Gemini. Ключ Gemini настраивается в Orbit AI. Для чтения координат и здоровья отметьте в Horizon разрешение локального режима перед запуском игры, а в оверлее нажмите **Обновить состояние**. Orbit показывает выбранные поля и прикладывает их к запросу только после отдельной отметки. Режим зависит от наличия `horizon-ctl`, поддержки команды и настроек самой версии Horizon; режим control может повлиять на паузу игры при потере фокуса. Управление персонажем с помощью ИИ в этой сборке не реализовано.

Если Windows сообщает об ошибке запуска Orbit, распакуйте полный архив ещё раз и запустите `Orbit-Diagnostics.cmd`. Отчёт не отправляется автоматически. Перед использованием его можно просмотреть.
