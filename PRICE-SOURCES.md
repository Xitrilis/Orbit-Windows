# Источники цен Orbit 0.19

Исходная ревизия — 23 октября 2026; источники повторно проверены 2 ноября 2026. Цены загружаются во время использования, в сборке нет таблицы зашитых цен. Покупки, авторизация и персональные предложения не запрашиваются. Публичная цена витрины не гарантирует возможность покупки на конкретном аккаунте.

С 0.16 пустая страна магазина наследует настройку Steam. Отдельная страна имеет приоритет, валюта не наследуется. Это регион публичной витрины, не проверка страны аккаунта. Запущенный Epic Games Launcher не передаёт эту настройку в Orbit.

Цены найденных товаров Epic обновляются через текущий официальный API `https://egs-platform-service.store.epicgames.com/api/v1/egs`: slug страницы разрешается в productId через `/mappings/{slug}`, затем запрашивается `/products/{productId}/offers/{offerId}` с `country` и `locale=en-US`. Проверяются ID предложения и sandbox, поддержка Windows, актуальное состояние покупки и валюта. Это позволяет получать свежую цену после окончания распродажи, когда зеркало ещё хранит прежнюю скидку.

Поиск Epic учитывает поля страниц товаров и частичные ошибки GraphQL. Если публичный GraphQL недоступен (403, 408, 429, 5xx, ошибка соединения или таймаут), используется [каталог EGData](https://docs.egdata.app/docs/offer-search) с региональными ценами. Orbit помечает такие цены как EGData и показывает дату обновления записи; перед покупкой цену нужно проверить на странице Epic. Для выбранного товара каталога используется точная пара namespace + offer ID. Для игры из библиотеки appName не считается offer ID: допускается лишь однозначное совпадение точного названия с явной пометкой. Ссылки на издания строятся по offer mapping конкретного издания.

| Источник | Используемые данные и адрес |
| --- | --- |
| Steam | `https://store.steampowered.com/api/storesearch/` и `https://store.steampowered.com/api/appdetails` — поиск, AppID, исходная цена `price_overview`, страна `cc`. Это публичные endpoints витрины, не гарантированно стабильный контракт Steamworks. Страна аккаунта вводится вручную: [пояснение Valve](https://help.steampowered.com/en/faqs/view/2B3F-DAEF-846B-A0E8). |
| Epic Games Store | `https://store.epicgames.com/graphql` — основной публичный каталог. При сетевой недоступности: `https://api.egdata.app/search/v2/search` и `GET /offers/{id}/price` как сторонний запасной источник; передаются только название игры и код страны, без данных аккаунта. Валюта и регион берутся из ответа, ссылка ведёт на конкретное издание Epic. [Региональные цены Epic](https://dev.epicgames.com/docs/epic-games-store/store-presence/custom-price-tiers). |
| GOG | `https://catalog.gog.com/v1/catalog` — `query=like:...`, `countryCode`, `currencyCode`, денежные поля `finalMoney/baseMoney`. Публичный интерфейс [каталога GOG](https://www.gog.com/en/games), его контракт может меняться. Валюта берётся из ответа, несовпадение с запросом отмечается. |
| Plati.Market | [Официальная документация поиска](https://plati.market/api/?f=7&show=xml): `https://plati.io/api/search.ashx` с `query`, `pagesize`, `pagenum`, `response=json`. Используются `price_rur`, название/описание, продавец, продажи и URL. Поисковый метод при проверке отвечал без ключа. [Общие условия API](https://plati.market/api/) предусматривают регистрацию/API-ключ для других операций; они здесь не вызываются. |
| FunPay | [Публичный каталог](https://funpay.com/) и страница соответствующего раздела ключей `/lots/<id>/`. Разбор HTML без исполнения скриптов, без входа и cookies. Цена — из видимого текста `.tc-price`, валюта — из `.unit`, тип/платформа/регион — из атрибутов и текста лота. Не выдаётся за официальный API. CAPTCHA/401/403/изменение разметки не обходятся. |
| Банк России | `https://www.cbr.ru/scripts/XML_daily.asp`, [документация XML](https://www.cbr.ru/development/sxml/) и [страница курса](https://www.cbr.ru/currency_base/daily/). Номинал учитывается: RUB за одну единицу = `Value / Nominal`; из исходной валюты в KZT — через RUB. Дата берётся из `ValCurs.Date`. Это справочный курс, а не курс оплаты. |

Настройки региона не изменяют страну настоящего аккаунта. Доступность оплаты и активации определяется магазином/продавцом. Orbit не использует пароли или сессии клиентов для цен и не публикует библиотеку пользователя целиком: сетевой запрос касается выбранной/искомой игры.

EA: поиск через публичный каталог `store.ea.com`; когда он возвращает другую страну, цены проверяются через официальный `https://drop-api.ea.com/game/{slug}?locale=en&override-country-code={country}`. Этот параметр использует сама витрина EA. Проверяются игра, PC-платформа EA app, доступность и точный ID издания. Валюта берётся из ответа: запрос KZ может вернуть RUB. Ссылка ведёт на страницу покупки выбранной игры в EA; состав издания указан отдельно.

Ubisoft: каталог и точный PC-вариант проверяются на `store.ubisoft.com`. Если публичная витрина отвечает для другой страны, подтверждённая цена показывается как справочная с фактическим регионом и не участвует в выборе лучшей цены. Это не цена Казахстана и не подтверждение возможности покупки. Для Battle.net автоматический источник пока не подключён.

 Нет полного поиска по всему рынку, подтверждения надёжности продавцов, проверки финальной комиссии, гарантии совпадения всех изданий или персональных скидок. Для Plati базовая цена всегда обозначена «от», а регион/издание выбираются на сайте. Для FunPay выводятся только лоты с явной поддержкой выбранных RU/KZ либо Global; остальные страны используют только Global.

Запросы ограничены таймаутом и размером ответа, данные кешируются в памяти. Неподдерживаемые форматы, неизвестные валюты и отсутствующие цены не превращаются в нули. Внешние тексты экранируются. Переходы в браузер разрешены только для ссылок из полученных результатов на выбранных доменах источников. Посторонние сайты и схемы `file:`, `javascript:`, протоколы запуска команд не принимаются.

Поиск Epic отбрасывает посторонние названия из нечёткого ответа каталога, сохраняя подходящие издания. Истёкшая скидка не выдаётся за текущую цену. В сравнении отдельно обозначаются: издание не найдено, цена устарела, регион не подтверждён и сбой источника. Ссылка поиска магазина не подписывается как страница найденной игры.
