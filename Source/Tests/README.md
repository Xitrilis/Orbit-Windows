# Проверки Orbit

Тесты не обращаются к аккаунтам и не запускают магазины.

В этой папке:

```powershell
npm install
npm test
npx playwright install chromium
npm run test:ui
npm run test:bridge
npm run test:assistant
dotnet run --project GeminiClientTests.csproj
```

`ORBIT_CHROME_PATH` позволяет использовать уже установленный совместимый Chromium.
Браузерные снимки сохраняются в `Orbit-Windows\qa`.

`native-bridge.cjs` подменяет CefSharp.PostMessage и проверяет сообщения интерфейса.
Он **не проверяет** работу настоящего CefSharp, Playnite, Windows UI Automation или клиентов магазинов.

`assistant-ui.cjs` проверяет кадр, явное прикрепление изображений/отчёта, подсказки, отмену, отображение ответов и ошибок как текста, очистку поля ключа и компактное окно.

`GeminiClientTests.csproj` выполняет 8 проверок настоящего C#-клиента с подменённым HTTP-транспортом: JSON, заголовок ключа, вложения, список моделей, извлечение ответа, ошибки квоты, отмена и валидация. Реальных API-запросов нет.


## Цены · 0.3

`dotnet run --project PriceServiceTests.csproj` — 12 изолированных проверок парсеров, валют, кеша, источников и ошибок. `-- --live` дополнительно делает реальные публичные GET-запросы по Cyberpunk 2077 для KZ (не покупает ничего), сохраняет временный результат в `qa/price-live.json`; цены зависят от даты/источников.

`node prices-ui.cjs` — сценарий интерфейса цен с имитацией CefSharp. `ORBIT_CHROME_PATH` позволяет указать путь Chromium/Chrome. Проверяет оригинальную валюту и RUB/KZT, «от», настройки, запросы, ссылки, отмену, поздние ответы, выбор копий, узкое окно и изоляцию демонстрации. Нативный контроллер, браузер Windows и диск не имитируются как успешно протестированные. Изображения QA пишутся локально и не входят в релиз.

## Пополнение Steam 0.4

```powershell
npm run test:wallet
dotnet run --project WalletServiceTests.csproj
# Необязательно: только GET общедоступных параметров, без логина и оплаты
dotnet run --project WalletServiceTests.csproj -- --live
```

20 проверок проверяют полную комиссию, округление, валюту, отказ при изменении страницы/формулы, лимиты и сбои. Браузерный сценарий использует вымышленные значения с подменой моста и ничего не оплачивает. `--live` читает HTML/JS сервиса и XML ЦБ, не создаёт заказ.


## Загрузки и интерфейс · 0.5

    npm run test:downloads
    dotnet run --project DownloadTelemetryTests.csproj

37 проверок телеметрии работают без Steam и Windows: локальные временные VDF и управляемые часы. Тест проверяет чтение без изменений исходного файла, повреждения/пустые данные, вычисление скорости/ETA, сброс после перерыва, распаковку отдельно от завершения и историю. downloads-ui.cjs использует подменённый мост, проверяет нижнюю панель, график, команды, отсутствие пересоздания карточек на каждом замере, компактный экран и анимации. Демонстрационные показатели не являются измерениями реальной загрузки.


## Оформление игр · 0.6

    npm run test:artwork
    dotnet run --project ArtworkStoreTests.csproj

31 проверка хранилища работает без Windows, в отдельном временном каталоге. Браузерный сценарий проверяет интерфейс, сообщения мосту и настоящее декодирование локального файла в демонстрации; выбор и нормализация файла в Windows требуют отдельной проверки на ПК.

## Распродажи 0.7

`dotnet run --project SaleServiceTests.csproj` проверяет календарь, историю/перезапуск/разделение товаров и регионов, атомарную запись и резервную копию, акции Epic, отсутствие вымышленных будущих цен, подборку Steam, точное межмагазинное сопоставление, ошибки и отмену. `-- --live` дополнительно проверяет публичные источники и сохраняет временные JSON в qa (в дистрибутив не входят).

`node sales-ui.cjs` — имитация моста: календарь, текущие акции, сортировка, минимум объявлений, наведение/фокус/клик, история по источникам, раздачи Epic, Escape, отмена/устаревшие ответы, компактное окно. Данные сценария вымышленные и предназначены только для теста.

## Главная 0.8

`npm run test:home` проверяет старт, поиск, приватность, отмену, поздние ответы, карточки, описание, цены/библиотеку, регион, 880×640 и демонстрацию с имитацией CefSharp. `dotnet run --project HomeTests.csproj` — 24 проверки запроса, режима, ID, каталога и контроллера. `-- --live` читает публичный Steam без покупки. Gemini подменён. Сценарии библиотеки теперь явно открывают «Все игры».

В 0.8 сценарий sales-ui.cjs также проверяет, что закреплённая кликом подсказка не исчезает при прокрутке модального окна.


## Недавние, фоновые клиенты и целостность 0.9

`npm run test:activity` — даты и история, полка главной, объединение копий, фильтры, настройки фона, компактное окно и демонстрация; используется имитация CefSharp.

`dotnet run --project ActivityTests.csproj` — 28 проверок истории на временных файлах и политики окон с подменённым Win32. Настоящие клиенты не запускаются и не закрываются.

`dotnet run --project StartupIntegrityTests.csproj` — 12 проверок файлов и настоящего RuntimeFiles.sha256 в полной распакованной сборке. Перед тестом изменённого проекта выполните Source/Build.ps1. Сам checkpoint без полного runtime для последней проверки не подходит.

`python Source/Package.py` из папки Orbit-Windows проверяет официальный runtime, версии и архитектуру, полные PE-секции, актуальность встроенного списка и готовые ZIP. Он не включает QA, пользовательские данные и инструменты тестовой среды.


## Логи и отчёт 0.10

`npm run test:support` проверяет состояние журнала, безопасный текст, локальные даты, экспорт/отмену/повтор, устаревшие ответы, обновление состояния, 880px, отсутствие IPC в демонстрации, минимальный состав сообщений об ошибках JavaScript, подавление повторов и отдельный экспорт при незагрузившемся app.js. Диалоги Windows имитированы.

`dotnet run --project SupportTests.csproj` — 18 проверок: ограничение размера/ротация, параллельная запись, повреждённые строки, отказ и восстановление записи, отсутствие секретов из Exception.Message/Data, фильтрация полей, ограниченное чтение Playnite, четыре разрешённых файла ZIP и атомарная замена без потери старого отчёта при ошибке.

В ActivityTests добавлены три случая: восстановление записи истории, восстановление записи состояния окон и сохранение исправной резервной копии при повреждённом основном файле. В activity-ui добавлена библиотека из 1000 игр/2000 сеансов с поиском, пагинацией и проверкой счётчиков.

QA-снимки, тестовые журналы и отчёты не входят в релиз. Эти проверки не подтверждают работу WPF/CefSharp и системных диалогов на настоящей Windows.


## Minecraft, очередь и заметки · 0.11

`npm test` — 18 тестов моделей (9 прежних и 9 новых). `npm run test:journal` — очередь, полка главной, поиск, черновики/поздние ответы/конфликт/повтор после отказа, общие заметки, установленная Epic-копия, компактное окно, read-only и изоляция демо. `npm run test:minecraft` — настройки/сканирование/стабильность DOM, моды/поиск/250 строк, импорт/отмена, Radmin/запуск, отсутствие автозапуска, устаревшие ответы, компактное окно и демо. Мост подменён; настоящих приложений и аккаунтов нет.

`dotnet run --project JournalTests.csproj` — 27 проверок хранения заметок и очереди, атомарности, конфликтов, восстановления, отсутствующих полей, будущей схемы и отказов записи.

`dotnet run --project MinecraftTests.csproj` — 33 проверки профилей Prism/CurseForge, каталогов Minecraft, архивов, недокачанных файлов, ограничений, добавления/переключения модов, запрета перезаписи, путей, аргументов запуска и сохранения настроек. Используются временные папки и искусственные JAR, не реальные моды. Проверка symbolic link выполняется в Linux; для неё на Windows могут потребоваться права создания ссылок.

В SupportTests добавлены приватные заметка и путь Minecraft в тестовую папку: в отчёт по-прежнему входят только четыре разрешённых файла, секреты не попадают. WPF/CefSharp, Microsoft/Java, Prism, Radmin, системные диалоги и LAN требуют отдельной проверки на Windows.
