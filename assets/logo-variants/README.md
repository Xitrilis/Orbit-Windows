# Варианты логотипа Orbit (концепты)

4 наброска в другом визуальном языке относительно текущего `assets/orbit-mark.svg`
(плоский mint-on-dark «планета + кольцо»). Это концепты для обсуждения, они **не подключены**
к сборке и не входят в `RuntimeFiles.sha256`.

| Файл | Стиль | Идея |
| --- | --- | --- |
| `01-neon.svg` / `.png` | Неон / кибер | Тёмная подложка, светящееся градиентное кольцо (cyan → violet → pink), «планета» с объёмом, звёзды |
| `02-minimal.svg` / `.png` | Минимализм | Светлая подложка, тонкие линии 1.6px, монохром — «чернила на бумаге» |
| `03-retro.svg` / `.png` | Ретро-закат (vaporwave) | Градиент фона purple → orange, «солнце»-планета с полосами, толстое кольцо `#ffd166` |
| `04-geo.svg` / `.png` | Геометрия / bold flat | Индиго-подложка, пунктирное толстое кольцо, планета-гексагон с фасеткой, квадрат-спутник |

- SVG — векторный источник (viewBox 96×96, как у текущего marca).
- PNG — превью 512×512, отрендерено локально (суперсемплинг 4×).

Чтобы опробовать в интерфейсе: заменить `assets/orbit-mark.svg` и `orbit.ico`
(нужна конвертация 16/32/48/256 px) и пересобрать — см. `Source/Build.ps1`.
