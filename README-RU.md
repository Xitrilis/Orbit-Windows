# Orbit 0.11 — Minecraft и твоя игровая очередь

Тестовая сборка единого игрового лаунчера для Windows 11 x64. Собственный интерфейс Orbit работает поверх включённого Playnite 10.63. Готовые исполняемые файлы находятся в архиве, исходники — в `Source`. Node.js и .NET SDK для запуска не нужны.

## Запуск

1. Полностью распакуй архив в папку с правом записи, например `D:\Apps\Orbit`.
2. Запусти `Orbit.exe`. Не запускай приложение прямо внутри ZIP.
3. Открой **Подключения**. Для каждого магазина войди в аккаунт, включи импорт неустановленных игр и сохрани настройки. Настройки интеграций и страницы входа открываются в окнах Playnite/сервиса.
4. Перейди в **Все игры** и нажми кнопку обновления справа от поиска. Первая загрузка обложек может занять несколько минут.

Если отдельно установленный Playnite уже запущен, сначала закрой его. Orbit использует свою копию, не меняет прежнюю библиотеку и не устанавливает ничего в автозагрузку.

Сохранено исправление неполной `engine/libcef.dll` из прежнего архива. Для повторной проверки распакуй 0.11 **в новую пустую папку** и запускай её `Orbit.exe`; старую папку пока сохрани. Не переноси в новую сборку старые DLL. Если уже настроены аккаунты, перенос данных описан в [STARTUP-FIX.md](STARTUP-FIX.md).

## Новое в 0.11

- **Minecraft** в боковом меню: обнаружение сборок Prism/CurseForge, импорт ZIP и .mrpack через установленный Prism, папка скачанных модпаков, добавление и переключение JAR. Нужна лицензия Java Edition, вход Microsoft и Java в Prism. Приложения Prism/Radmin не входят в архив. Подробно: [MINECRAFT.md](MINECRAFT.md).
- **Radmin VPN**: предложение открыть установленное приложение перед запуском сборки и шаги для совместной игры. Подключение обоих ПК к общей сети выполняется в Radmin.
- **Поиграть позже**: отдельная очередь, фильтр установленных игр, перемещение в начало и полка на главной.
- **Заметки**: общие для копий игры, локальное сохранение, резервная копия и защита от конфликтов. Черновик сохраняется при закрытии окна до выхода из Orbit.
- **Во что сыграть?**: фильтры, отсутствие повторов до конца подборки и запуск установленной копии без изменения предпочтения Steam. Подробно: [JOURNAL.md](JOURNAL.md).

Импорт CurseForge в Prism создаёт отдельную копию. Изменения исходной сборки автоматически не синхронизируются. Запуск Windows, вход Microsoft и совместная игра пока не проверены на настоящем ПК; файловые и браузерные проверки описаны в [VALIDATION.md](VALIDATION.md).

## Новое в 0.10

- **Настройки → Помощь и отчёт об ошибке**: состояние журнала, последние ошибки и сохранение ZIP. Экспорт также доступен в меню значка Orbit возле часов.
- Если основной интерфейс не загрузился, отдельное уведомление предлагает сохранить отчёт. Если Orbit вообще не открывается, запусти **Orbit-Diagnostics.cmd**: он проверит компоненты и попробует создать ZIP рядом с приложением.
- Локальные журналы ограничены примерно 3 МиБ, повторяющиеся события подавляются. В ZIP попадают технические события, версия, счётчики и известные признаки ошибок Playnite. Ключи Gemini, запросы, пароли, снимки и история игр не включаются; автоматической отправки нет. Чтобы я мог разобрать сбой, прикрепи ZIP в чат. Подробнее — [SUPPORT.md](SUPPORT.md).
- История быстрее сопоставляет сеансы с большой библиотекой. Исправная резервная копия сохраняется при восстановлении повреждённого основного файла. Предупреждения о невозможности записи истории и состояния фоновых окон исчезают после успешного сохранения.
- Добавлена обработка сбоев отложенных действий интерфейса с кодом ошибки. Команда запуска игнорируется, если игра уже имеет состояние «запускается» или «работает».

## Сохранено из 0.9

- **Недавние** в боковой панели: последние игры и все записанные запуски, дата, время, магазин, поиск и фильтр. На главной — последние четыре игры; в карточке — последние пять запусков.
- **Настройки → Клиенты магазинов в фоне**: после импорта или успешного запуска игры Orbit скрывает распознанные главные окна клиентов, сохраняя их процессы. Кнопки «Убрать окна в фон» и «Показать окна клиентов» доступны здесь; восстановление окон есть и в меню трея Orbit.
- При старте проверяются размеры и SHA-256 файлов сборки по списку, встроенному в Orbit.exe. При повреждении показывается имя компонента. Отдельная проверка: **Orbit-Diagnostics.cmd**.

История не создаётся при одном нажатии «Играть». Прежние даты импортированной библиотеки помечены отдельно; полной старой истории у магазинов может не быть. Время отображается по Windows. После прерывания отслеживания окончание сеанса не выдумывается.

Фоновые окна скрываются только при уверенном распознавании клиента. Авторизация, неизвестные окна, изменившиеся заголовки и ограничения прав могут потребовать ручного действия. Нативная работа на Windows пока не проверена. Подробности — [ACTIVITY.md](ACTIVITY.md).

## Главная и поиск игр

Orbit запускается на **Главной**: обложка игры, ближайшие распродажи, подборки, скидки и свежие релизы Steam. В «Во что хочется поиграть?» доступны обычный поиск и подбор Gemini: например, «несложные головоломки вдвоём». Выбирай один ПК/сеть и поиск только в коллекции. «Настроить ИИ» использует существующие ключ и модель Orbit AI.

Нажми на обложку: описание → своя копия в библиотеке либо цены. Новые варианты проверяются по Steam, свои — по импортированным данным. Примеры не отправляются автоматически. Состав запроса и ограничения — [HOME.md](HOME.md).

## Цены, распродажи и история

Открой **Магазин**. После выбора региона нажми **Скидки и события**, чтобы увидеть календарь и подборку актуальных акций Steam. При следующем открытии магазина они загружаются автоматически. Выбери игру из подборки или найди нужное издание поиском. Из библиотеки: игра → **Цены и распродажи**.

- Сверху — цена выбранного магазина и минимум среди полученных предложений. Магазины ниже сортируются по цене в общей валюте, без обязательного первого места Steam. При отсутствии общего курса минимум не выбирается.
- Для Steam, Epic и GOG используются настройки страны и валюты каждого аккаунта. Для сравнения настрой каждый магазин. Совпадение в другом магазине допускается только при одном точном нормализованном названии; состав издания всё равно следует проверить. Сиквелы и несколько неоднозначных совпадений не подставляются.
- Наведи на название магазина/площадки или нажми на него. Откроется подсказка: текущая скидка, ближайшая объявленная акция, ранее зафиксированная цена и минимум наблюдений. Работают Tab, Enter и Escape; Escape сначала закрывает подсказку.
- Событие магазина не означает участия конкретной игры. Steamworks публикует даты, но не будущие цены отдельных игр. Числа не прогнозируются. Для Epic сопоставляются ID предложения и namespace; явно объявленная бесплатная раздача показывается как будущая нулевая цена. Другие проценты не пересчитываются в обещанную будущую цену.
- История накапливается только при проверке цен в Orbit, отдельно для товара/лота, региона и валюты. До первой проверки прошлой цены может не быть. Это не импорт полной истории SteamDB/ITAD и не непрерывный мониторинг. Цена «до скидки» магазина не считается прошлой реально наблюдавшейся ценой.
- FunPay и Plati сохраняют условия продавца. У Plati остаётся пометка **«От»**, выбранный регион не подтверждён; минимум объявлений не означает гарантированно такую же игру и окончательную сумму покупки.

Календарь Steam обновляется из официального Steamworks; при ошибке показана явно помеченная сохранённая копия. Включён отдельный официальный анонс Epic Halloween Sale 2026, проверенный 24.10.2026. Это датированный анонс, не автоматически обновляемый календарь всех событий Epic. Будущие даты GOG, FunPay и Plati не подключены; текущие цены и наблюдения доступны. Для EA, Ubisoft и Battle.net автоматические цены по-прежнему не подключены.

История: `engine/OrbitData/price-history.json`, резервная копия `.bak`. Хранятся до 1000 серий, до 96 наблюдений за два года в каждой. Нет записи паролей, аккаунтов или платёжных данных. Подробные источники и ограничения — [SALES.md](SALES.md).

## Свои иконки, обложки и баннеры

1. Открой игру в библиотеке → **Оформление**.
2. Нажми **+** рядом со значком, обложкой или баннером либо выбери элемент и нажми **Выбрать файл**.
3. Выбери PNG, JPG или BMP до 20 МБ. Для значка также поддерживается ICO; используется самый крупный кадр. Изображение должно быть не больше 40 мегапикселей.
4. Настрой положение по горизонтали/вертикали и масштаб 100–200%. Результат сразу виден в предпросмотре.
5. Нажми **Сохранить оформление**. Изменённые элементы применятся ко всем копиям в этой карточке. Нетронутые элементы каждой копии сохраняются.
6. **Сбросить** возвращает выбранный элемент к изображению магазина; **Вернуть всё исходное** сбрасывает три элемента и кадрирование. Сброс нужно сохранить. **Отменить**, Escape или крестик редактора закрывают его без применения несохранённых изменений.

Своя иконка видна возле названия на карточке, в списке и в подробностях игры. Обложка меняется в библиотеке и загрузках. Баннер используется на главном экране и в подробностях. Кадрирование хранится отдельно и не обрезает файл.

Изображения копируются внутрь Orbit и преобразуются в PNG. Исходный файл можно после сохранения переместить; папки и метаданные магазинов не изменяются. Длинная сторона копии ограничена 512 px для значка, 1800 px для обложки и 2560 px для баннера. WEBP, SVG, анимации и загрузка изображений по ссылке в этом выпуске не поддерживаются.

Оформление хранится в engine/OrbitData/Artwork/artwork.json, изображения — в подпапке images. При резервном копировании сохраняй всю папку engine/OrbitData. Обычное обновление библиотеки и переключение Steam/Epic/GOG не сбрасывают оформление. Новая копия игры, импортированная позже, получает своё оформление при следующем сохранении изменяемых элементов. Если игра удалена и импортирована с новым идентификатором, оформление автоматически не переносится.

Демонстрация позволяет выбирать свои файлы и пробовать кадрирование, но изменения существуют только в памяти вкладки. Сохранение на диск доступно в Orbit.exe.

## Загрузки и обновлённый интерфейс

Нажми полосу **Загрузки** внизу окна. Во время установки на ней показаны игра, магазин, прогресс, скорость и примерное оставшееся время. Полоса остаётся видимой при просмотре библиотеки.

На отдельном экране: загруженный и оставшийся объём, средняя скорость, примерное время до конца скачивания, прошедшее время, график за последние пять минут и список установок. Нажми строку игры, чтобы переключить подробности. Наведение на график показывает значение замера. Кнопка **В библиотеку**, повторный клик по нижней полосе или Escape возвращают к коллекции.

**Подробные показатели пока подключены только для Steam**, когда его локальный манифест содержит счётчики. Они могут обновляться с задержкой. Скорость рассчитывается по изменениям объёма за окно около 30 секунд; примерное время не включает распаковку, проверку и установку. При отсутствии свежих данных показаны «—» и «Уточняется». Остальные магазины показывают этап установки и кнопку открытия клиента.

100% скачанного объёма означает переход к обработке файлов. **Играть** появляется после подтверждения установки библиотекой. Завершённую запись можно убрать из списка. Пауза, возобновление и отмена скачивания пока выполняются в родном клиенте.

В 0.5 унифицированы кнопки, отступы, карточки, панели настроек и модальные окна. Переходы и реакции на наведение стали плавнее. Обновление показателей не пересоздаёт карточки и не сбрасывает прокрутку. Анимации можно отключить в настройках Orbit; системное предпочтение уменьшенного движения также учитывается.

Подробности источника данных и проверок: DOWNLOADS.md, VALIDATION.md. Демонстрация содержит явно помеченные вымышленные показатели, не выполняет скачивание и не отправляет команды магазинам.

## Пополнение Steam

1. Открой **Пополнить Steam** слева. Укажи логин для входа в Steam и регион RU/KZ.
2. Введи сумму до комиссий в рублях, выбери СБП или карту → **Рассчитать стоимость**.
3. Orbit загрузит публичные параметры GAMEMONEY: комиссии, ожидаемое списание и зачисление. Для ₽/₸ используется справочный курс ЦБ. Расчёт действителен пять минут.
4. Для сравнения с МТС открой его сайт и внеси обе итоговые суммы в **Сравнить итоговые суммы**. Минимальная комиссия на всём рынке не гарантируется.
5. Нажми **Продолжить с GAMEMONEY**, проверь логин/регион → перейди на сайт. Скопируй логин кнопкой, перенеси сумму и выбери там тот же способ оплаты. Данные не подставляются автоматически.
6. Подтверди итог и оплату на странице сервиса. Баланс проверяется в Steam; Orbit не получает подтверждение платежа.

**Собственной привязки карты в Orbit пока нет.** Если платёжный сервис предлагает сохранить карту, это происходит на его стороне. СБП не требует ввода карты в Orbit. Пароль Steam, карта и банковские коды в лаунчер не вводятся. Логин сохраняется только по флажку и кнопке сохранения.

Подробности проверки комиссий, отзывов, источники и ограничения: `WALLET-SOURCES.md`.

## Магазин и сравнение цен

1. Открой **Магазин** слева → **Регионы и валюты**.
2. Для каждого аккаунта укажи страну: например `KZ` — Казахстан, `RU` — Россия. В поле есть список подсказок. Валюта — например `KZT` или `RUB`; пустое поле означает валюту ответа магазина. Для GOG при пустом поле запрашивается USD.
3. Сохрани настройки. Они относятся только к отображению цен в Orbit: страна и валюта настоящего аккаунта магазина не изменяются.
4. Выбери Steam, Epic Games или GOG, введи название игры и нажми **Найти игру**. Выбери нужное издание в результатах.
5. В карточке сравнения видны цена магазина и предложения FunPay / Plati.Market. Для уже добавленной игры доступна кнопка **Цены и распродажи** в её карточке. Если копий несколько, можно переключать их.
6. **Обновить** запрашивает данные заново. Кнопки источников открывают соответствующие страницы в браузере. Покупка и оплата выполняются там вручную.

**Что показывается:** исходная сумма и валюта, рубли и тенге, ссылка на источник, время получения цены. `≈` означает пересчёт по опубликованному курсу Банка России с указанной датой. Это не самостоятельная цена другого региона и не курс банка при оплате. Если курс или цена недоступны, сумма не придумывается. Валюта фактического ответа магазина сохраняется; несовпадение с указанной валютой аккаунта отмечается в карточке.

| Источник | Поддержка в 0.3 |
| --- | --- |
| Steam | Поиск каталога и цена конкретного AppID для выбранной страны через публичную витрину |
| Epic Games | Поиск и цены конкретного предложения через публичную витрину с параметром страны |
| GOG | Поиск каталога, страна и запрошенная валюта; фактически возвращённая валюта показана явно |
| FunPay | Чтение публичного раздела ключей. Тип, продавец, цена из видимого текста, платформа и заявленный регион лота |
| Plati.Market | Официальный поисковый интерфейс: базовая цена **«от»**, тип по описанию, продавец и ссылка |
| EA / Ubisoft / Battle.net | Автоматические цены пока не подключены. Есть переход в соответствующий магазин; цена Steam не подставляется |

FunPay: автоматически выбирается только раздел с точно совпавшим названием игры. Если раздел не найден, раскрой **Уточнить раздел FunPay для этой игры** и вставь URL раздела ключей. Лоты фильтруются по названию, типу передачи, изданию и платформе ПК. Для RU/KZ учитывается явно заявленный соответствующий регион или Global; для остальных стран — только явно заявленный Global. СНГ и неизвестные регионы не считаются доказательством совместимости. Фильтр консервативный, поэтому часть подходящих лотов может не попасть в результаты. Обрабатывается до 3000 строк страницы, выводится до 8 предложений; это не полный поиск минимальной цены по площадке.

Plati: проверяется первая страница из 50 результатов, выводится до 8 ключей/подарков. **Базовая цена не считается итогом для выбранного региона.** Регион, издание, дополнительные параметры и способ оплаты выбираются у продавца и могут изменить цену. Такие предложения вынесены отдельно; Orbit не объявляет их «самыми выгодными». Неясные товары, аккаунты, аренда, пополнения и распространённые обозначения других изданий/дополнений отфильтровываются по тексту. Классификация не гарантирует содержимое покупки; перед оплатой прочитай лот.

Наличие цены из первичного источника не подтверждает надёжность отдельного продавца, доступность активации или итоговую стоимость оплаты. Сравнение предназначено для выбора и проверки предложений. Сессии магазинов не используются для цен; персональные скидки/купоны не учитываются. Регион указывается вручную, не определяется из IP и не извлекается из паролей или файлов авторизации.

Запросы идут напрямую к источникам без серверного посредника Orbit и без API-ключей. Название искомой игры передаётся соответствующим витринам/площадкам. Только чтение; никаких автоматических покупок, входа, решения CAPTCHA или изменений аккаунта. Цены кешируются в памяти до 5 минут, справочник FunPay и курс — до 6 часов; время источника не заменяется временем просмотра кеша. **Обновить** обходит кеш. После выхода кеш пропадает. Курс старше 14 дней не используется. Если площадка изменит формат ответа или ограничит запросы, будет показана ошибка/отсутствие данных и ссылка.

Регионы и ссылки разделов сохраняются в `engine\OrbitData\price-settings.json`. Демонстрационный режим не запрашивает и не выдумывает цены. В `PRICE-SOURCES.md` указаны использованные источники и границы проверки.

## ИИ-помощник и оверлей

1. Нажми **Orbit AI** слева или **Спросить Orbit** в карточке игры.
2. Открой вкладку **Настройки** помощника → **Открыть Google AI Studio**.
3. Создай свой Gemini API-ключ и вставь его в поле в Orbit. Обычный вход в чат Gemini не подставляет ключ автоматически.
4. Нажми **Сохранить и получить модели**, выбери подходящую модель и нажми **Сохранить**. Список загружается через API, а не зашит в приложение. Для вопросов по кадру нужна поддержка изображений.
5. Запусти игру. Нажми **Ctrl + Shift + Space**: Orbit попытается определить её по пути процесса и снимет видимую область окна до появления панели. Если окно не связано с установленной игрой, кадр не создаётся.
6. Посмотри предпросмотр, напиши вопрос и нажми **Спросить** или **Ctrl + Enter**. Нажатие на подсказку только заполняет вопрос.
7. **Escape**, крестик или повторное сочетание скрывают панель и убирают кадр из её памяти. Для свежего кадра вернись в игру и нажми сочетание снова.

Горячую клавишу можно поменять на Alt + Shift + Space, Ctrl + Alt + Space или отключить. Если сочетание занято, настройки покажут ошибку регистрации.

Панель рассчитана на оконный и безрамочный режим. Эксклюзивный полный экран, защищённый вывод, повышенные права игры, неизвестная папка запуска или ограничения захвата могут не дать открыть оверлей или получить изображение. В процессы игр ничего не внедряется; совместимость с конкретной игрой/античитом не гарантируется. Игра автоматически не ставится на паузу.

Это анализ **одного кадра по нажатию**, не постоянное наблюдение. На снимок видимой области могут попасть уведомления или другие оверлеи — проверяй предпросмотр. Снимок хранится в памяти, не сохраняется в файл и отправляется в Google только с вопросом при отмеченном переключателе. Можно убрать кадр или снять отметку. Отчёт диагностики тоже прикрепляется отдельно.

Запрос отправляет напрямую в Gemini API текст вопроса, название игры/магазина, до 10 предыдущих текстовых сообщений и выбранные вложения. Старые кадры повторно не отправляются. Диалог хранится в памяти текущего процесса; смена игры и кнопка очистки начинают новый диалог. История исчезает после выхода. Отмена останавливает ожидание запроса, но не отзывает уже отправленные Google данные.

API-ключ защищён Windows DPAPI для текущего пользователя и хранится в `engine\OrbitData\ai-key.bin`. Он не выводится в ответах, URL или отчётах. Настройки модели и сочетания — в `ai-settings.json`. Ключ можно удалить в настройках; после переноса папки на другой ПК/пользователя потребуется ввести его заново.

Gemini API требует доступного в твоём регионе аккаунта и API-ключа. Квоты и возможная оплата определяются Google и твоим проектом. Встроенных оплаченных ключей в Orbit нет. ИИ отвечает на вопросы, но не выполняет команды, не нажимает кнопки игры и может ошибаться. Веб-поиск и проверка свежих игровых обновлений не включены.

## Проверка игры

В карточке игры нажми **Проверить игру**. Локальный отчёт показывает:

- состояние установки в библиотеке;
- доступность папки и файла запуска, если интеграция предоставила их;
- свободное место на соответствующем диске;
- события сбоев/зависаний Windows Application за последние 7 дней, которые удалось связать с путём игры. Просмотр ограничен 600 последними подходящими событиями и временем выполнения, результат может быть неполным.

Отчёт можно сохранить как TXT или выбрать **Разобрать с ИИ**. Второе действие заполняет вопрос и отмечает отчёт; отправка происходит только после нажатия **Спросить**. Некоторые персональные пути и очевидные секреты маскируются, но перед отправкой всё равно проверь содержание.

Зелёная отметка наличия файла не означает, что содержимое исправно. Кнопка **Проверить файлы в Steam** передаёт запрос `steam://validate/<appid>` родному клиенту. Подтверждение и результат доступны в Steam. Для остальных магазинов Orbit открывает клиент; проверку/восстановление нужно выбрать в меню игры вручную. Перед проверкой закрой игру: магазин может заново скачать изменённые или повреждённые файлы. Результат проверки файлов Orbit пока не получает.

## Что сделано

- Steam, Epic Games, EA app, Battle.net, Ubisoft Connect и GOG. Xbox исключён.
- Общая библиотека установленных и неустановленных игр после настройки импорта.
- Карточки и список, поиск, фильтры магазина/жанра/установки/избранного, сортировка, случайная игра с предпочтением установленных.
- Одна карточка одинаковых игр. Кликабельный магазин под названием; по умолчанию Steam; запоминание выбранной копии. Разные издания и ремастеры не объединяются автоматически. Ручное объединение/разделение доступно в карточке игры.
- Избранное, данные времени игры, запуск выбранной копии через её интеграцию.
- Свой экран установки, выбор папки и отображение свободного места.
- Изолированный помощник Windows UI Automation пытается выбрать путь и нажать установку только после проверки игры и пути. Не нажимает по координатам, не принимает соглашения, не редактирует конфигурации Steam, не закрывает другие приложения.
- Центр загрузок с нижней панелью, объёмом, скоростью, примерным временем и графиком Steam. История установок сохраняется, график хранится в памяти текущего сеанса. Завершение подтверждается состоянием библиотеки.
- Трей, поиск по Ctrl+K, разворачивание по F11, плавные переходы и отключение анимаций.

## Ограничения этой сборки

**Это не проверенный на реальных аккаунтах релиз.** Скомпилированы Windows EXE/DLL, проверены логика библиотеки, интерфейсы в Chromium, расчёты цен и Gemini-клиент с имитацией HTTP-ответов. Получены живые ответы цен Steam, Epic, GOG, FunPay, Plati и курса ЦБ из Linux. В этой среде нет Windows, авторизованных клиентов и твоего API-ключа. Вход, реальный запуск игр, трей, установка, горячая клавиша, захват, DPAPI, чтение событий и живые ответы Gemini требуют проверки на ПК.

**Установка из Orbit экспериментальная.** Универсального API управления установкой у шести клиентов нет. Помощник зависит от доступности элементов текущего окна клиента через Windows UI Automation. Проверка папки и кнопки установки реализована для русских/английских надписей. При изменении интерфейса, недоступности UI Automation, повышенных правах клиента, запросе входа/соглашения/защиты автоматизация останавливается. В окне загрузок появится причина и кнопка открытия клиента. Гарантировать полностью скрытые окна клиентов пока нельзя.

В Steam выбирается уже зарегистрированная библиотека. Добавление новой библиотеки выполняется в Steam → Настройки → Хранилище. Имя конечной папки игры назначает Steam. Автоматическое создание новой библиотеки из Orbit не реализовано.

Пауза/отмена самой загрузки, лимит скорости, общая очередь скачивания и данные скорости всех клиентов пока остаются в родных клиентах. Кнопка «Остановить подготовку» останавливает только помощник; начатое скачивание она не отменяет. Установки, запущенные вне Orbit, не попадают в его историю автоматически.

Просмотр уже импортированной библиотеки не требует одновременного запуска магазинов. Нужный клиент может запускаться для входа, установки, проверки лицензии и игры. Некоторые игры Steam требуют также EA/Ubisoft или другой клиент издателя; исключить эту зависимость Orbit не может. DRM не обходится.

Ubisoft получает список из локальных данных Ubisoft Connect: сначала войди в него. Поддержка отдельных игр и импорт всей библиотеки зависят от интеграций и доступности сервисов. Нулевое число игр не означает успешный вход. Ошибки импорта показываются в Orbit, подробности доступны в Playnite.

## Данные и восстановление

- `engine\library` — база игр и обложки.
- Настройки интеграций и данные сессий Playnite также хранятся внутри `engine`.
- `engine\OrbitData\preferences.json` — настройки интерфейса, группировка и выбранные магазины; предыдущая версия сохраняется в `.bak`.
- `engine\OrbitData\downloads.json` — история установки, без паролей.
- Кнопка **Настройки → Открыть Playnite** позволяет открыть основу для дополнительной диагностики. Можно также запустить `engine\Playnite.DesktopApp.exe`.

Не отправляй всю рабочую папку другим людям после входа: в ней могут быть сессии аккаунтов. Исходный архив до первого запуска аккаунтов не содержит. Демонстрационная коллекция включается отдельно и не смешивается с настоящими играми; в демонстрации нет действий с клиентами.

Если Windows показывает сообщение об издателе, учти, что собственные файлы Orbit не подписаны коммерческим сертификатом. Защиту Windows отключать не требуется. Оригинальные компоненты Playnite сохранены отдельно.

## Разработка

Интерфейс: `engine\Extensions\Orbit\ui`. Открой `index.html?demo=1` в браузере для демонстрации библиотеки или `assistant.html?demo=1` для оформления помощника. Без параметра демонстрации данные не подставляются. Браузерная версия не управляет Windows и не отправляет запросы к Gemini.

Для пересборки собственных файлов установи .NET 8 SDK и запусти `Source\Build.ps1`. Приложение использует .NET Framework 4.6.2 API, доступные в .NET Framework Windows 11; основа Playnite — 32-разрядная, загрузчик и помощник — 64-разрядные.

`Source\Tests` содержит тесты модели и браузерные сценарии. `VALIDATION.md` описывает выполненные проверки и непроверенные части. Лицензии и источники внешних компонентов — в `THIRD-PARTY.md`, `Notices` и `engine\license.txt`.
