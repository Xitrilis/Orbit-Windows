# Orbit: руководство по версии 0.19

Orbit объединяет игры из нескольких магазинов в одном окне Windows. Интерфейс работает поверх Playnite 10.63; приложения магазинов сохраняют ответственность за вход, лицензии, установку и запуск. Эта инструкция относится к коду в `main`. На странице [Releases](https://github.com/Xitrilis/Orbit-Windows/releases) пока опубликован более старый полный архив `v0.11.0`.

## Как запустить

1. Распакуйте **полный архив Orbit-Windows** в новую папку с правом записи. Git-клон неполон: крупный runtime Playnite в него не входит.
2. Запустите `Orbit.exe` из распакованной папки. Не запускайте файл прямо из ZIP.
3. Откройте **Подключения** и войдите в нужные магазины. Если хотите видеть неустановленные игры, включите их импорт в настройках соответствующей интеграции.
4. Откройте **Все игры** и обновите библиотеку. При первом запуске импорт и получение обложек могут занять несколько минут.

Если отдельно запущен Playnite, закройте его перед первым запуском Orbit. Для диагностики есть `Orbit-Diagnostics.cmd`; действия при сбое описаны в [SUPPORT.md](SUPPORT.md). При переходе на новый полный архив сохраняйте прежнюю папку, пока не перенесёте данные по [STARTUP-FIX.md](STARTUP-FIX.md).

## Библиотека и игры

Orbit импортирует библиотеку Steam, Epic Games, EA app, Ubisoft Connect, GOG и Battle.net через интеграции Playnite. Одна карточка может содержать несколько копий игры; в карточке выбирается копия для запуска. Доступны поиск, фильтры, избранное, недавние игры, очередь «Поиграть позже», заметки и оформление карточек. Клиент магазина может понадобиться при входе, установке, проверке лицензии и запуске игры; Orbit не обходит DRM.

Для Minecraft требуется отдельно установленный Prism Launcher. Импорт ZIP/.mrpack передаётся в Prism, вход Microsoft и Java настраиваются там. Подробности — [MINECRAFT.md](MINECRAFT.md). Интеграции [Horizon](HORIZON-START-RU.md) и [Radmin](RADMIN-START-RU.md) тоже требуют соответствующих сторонних программ.

## Магазин и цены

В **Магазине** выберите витрину и найдите игру. Orbit показывает исходную цену и, когда курс доступен, приблизительный пересчёт в RUB/KZT. Регион публичной витрины можно указать в настройках цен. Если страна Epic не задана отдельно, используется страна Steam; валюта другого магазина автоматически не меняется. Настройки Orbit не меняют страну вашего аккаунта.

| Источник | Что доступно |
| --- | --- |
| Steam | Поиск, цена по AppID и выбранной стране |
| Epic Games | Поиск конкретного издания, актуальная цена предложения и ссылка на его страницу; при недоступности каталога может использоваться помеченный источник EGData |
| GOG | Поиск и цена в фактически возвращённой валюте |
| EA app | Поиск PC-издания и проверка региональной цены |
| Ubisoft Connect | Поиск PC-издания; цена другой региональной витрины помечается как справочная и не участвует в выборе лучшего предложения |
| Battle.net | Переход в магазин; автоматические цены пока не подключены |
| FunPay / Plati | Отдельные предложения продавцов с условиями и ограничениями |

Если магазин не подтвердил издание или цену, Orbit показывает причину и ссылку на поиск. Он не подставляет цену другой игры или другого региона как цену вашего аккаунта. У Sons of the Forest, например, отсутствие подтверждённого предложения в Epic/GOG не означает ошибочную нулевую цену. Перед покупкой проверьте страницу магазина, регион активации, издание и итоговую сумму. Методы получения и границы проверки описаны в [PRICE-SOURCES.md](PRICE-SOURCES.md).

## Загрузки и фоновые клиенты

Orbit показывает состояние установки и данные загрузки Steam, когда они доступны. Сама установка выполняется в клиенте магазина; автоматический выбор пути через Windows UI Automation зависит от текущего интерфейса клиента и может потребовать ручного продолжения. При полном выходе из Orbit распознанные скрытые окна клиентов возвращаются. Дополнительные сведения — [DOWNLOADS.md](DOWNLOADS.md) и [ACTIVITY.md](ACTIVITY.md).

## Orbit AI

Помощник использует ваш собственный ключ Gemini API. Откройте **Orbit AI → Настройки**, укажите ключ, получите список моделей и сохраните выбор. Для вопроса по игре можно отдельно прикрепить снимок видимой области окна. Снимок показывается до отправки; сам по себе запуск игры или открытие панели его не отправляет. Доступность моделей, квоты и возможная оплата зависят от Google.

Ключ хранится локально в `engine/OrbitData/ai-key.bin` с защитой Windows DPAPI для текущего пользователя. На другом компьютере его потребуется ввести снова. Настройки и библиотека тоже лежат в рабочей папке; не выкладывайте папку после входа в аккаунты. Подробности о диагностических отчётах — в [SUPPORT.md](SUPPORT.md).

## Разработка и ограничения

Собственный код находится в `Source/`, интерфейс — в `engine/Extensions/Orbit/ui/`. Для пересборки нужны .NET 8 SDK, Windows и полный runtime Playnite 10.63. Сборка выполняется `./Source/Build.ps1`, проверки и упаковка описаны в [README.md](README.md) и [Source/Tests/README.md](Source/Tests/README.md).

Версия `main` активно дорабатывается. Некоторые цены зависят от публичных витрин и могут исчезать при ограничении запросов или изменении их формата. Персональные скидки, итоговая комиссия оплаты и доступность товара на вашем аккаунте автоматически не подтверждаются. История изменений и границы выполненных проверок — [AUDIT-0.19.md](AUDIT-0.19.md) и [VALIDATION.md](VALIDATION.md).
