- Визуально просмотрены очередь, редактор заметки, случайная игра, Minecraft, моды, настройки и окно совместной игры; проверена компактная раскладка. QA-снимки и пользовательские данные исключены из дистрибутива.

Поддержка манифеста JAR не означает проверку совместимости модов. Команда запуска не считается подтверждённым игровым сеансом. Подробности — MINECRAFT.md и JOURNAL.md. ## Дополнительно в 0.9

- Подтверждён дефект прежнего архива: libcef.dll была неполной (39 660 608 вместо 238 191 616 байт). Она заменена из официального Playnite 10.63. Все 876 включённых файлов оригинального runtime без PDB проверены по длине и CRC из исходного 7z, затем по SHA-256. ## Требует проверки на Windows

- Первый запуск `Orbit.exe`, загрузка расширения в Playnite, CefSharp, значок трея и повторное открытие.
- Вход и импорт каждой из шести библиотек, включая игры, которые ещё не установлены.
- Запуск выбранной копии игры, обновление её состояния и времени игры.
- Windows UI Automation: поиск окна, распознавание папки, подтверждение установки в актуальных русских/английских клиентах.
- Прогресс Steam из реального appmanifest; обновление статуса после завершения установки.
- Поведение при недоступной сети, изменении интерфейса магазина и запросе входа.
- Пересборка через `Source/Build.ps1` на Windows с .NET SDK. Поставляемые EXE/DLL уже скомпилированы прямым вызовом того же компилятора Roslyn.
